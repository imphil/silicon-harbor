# Settings

| Section           | What it holds                                                                                                                                                                   |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **This computer** | The tools environments need and their state; see [](first-run.md).                                                                                                              |
| **Credentials**   | github.ibm.com, Artifactory and IBM Cloud; see [](credentials.md).                                                                                                              |
| **IDE**           | The IDEs found on this computer. New environments open in the one you **Use by default**; IBM Bob is recommended. A missing IDE has a **Download** button to its vendor's page. |
| **Updates**       | The versions of Silicon Harbor and its Devsy engine, and whether to check for updates automatically.                                                                            |
| **Support**       | **Copy diagnostics** for a support request: the app and engine logs and the results of the computer check, no source code or passwords.                                         |
